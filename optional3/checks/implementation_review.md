# 本地实现核验记录

核验范围为optional3-guard-v1本地工具和预设测试夹具，不是模型红队结果，也不是人工POC审批或沙箱证据。

实际运行prepare.py生成18个案例、36份输入；运行self_test.py通过43/43项。测试覆盖输入标记、伪造引文、越界行号、错误漏洞类型、partial错误结论、合成标记泄露、越界路径、危险Python调用、缺少审批声明、完整/缺失/重复指标记录和零分母。

input_review.csv显示12个预设攻击均产生审查信号，6个正常对照中N02、N03、N06也产生信号；输入工具均未自动拒绝。这里的信号命中不代表成功阻断，更不代表模型误拒率为0。

模型指标工具读取36条pending记录，两组所有实际模型比率均为unmeasured，没有将空白算为0或成功。指标测试中的伪数据只在临时测试目录中创建并清理，不写入正式模型原文、审批或评测CSV。

审批工具没有执行接口。测试只调用审批资格判断函数，未产生真实审批记录。当前没有Docker运行与隔离证据，不能称沙箱已验证。所有脚本静态通过后仍需人工审查；动态URL、间接行为及资源问题依赖外部隔离。
