# 选做1 实验配置与历史偏差

本次采用已有实验的离线复算协议，不把分析日期当作模型运行日期。原始结果来自2026年10月19日，分析基线冻结于2026年10月20日。

## 样本和版本

- 源提交：`533b87dd1225d6bd11cb8bdc98b0f2f91eb69617`。
- 14个父样本、17包输入，输入版本v2；数据区内容在所有比较组中一致。
- 主比较：v1=`wp2-eval-42/v1`，v2=`wp2-eval-42/v2`，v3=`wp4-final-wp4-v2/final-wp4-v2`。
- 补充组：原三版final、WP4基线final、WP4中间版final-wp4-v1。
- 三版完整输入见`raw_inputs/`；三版汇编见`prompts/`。汇编标题不属于历史模型输入。
- 源输出只复制，原版名、字段、引文、代码不修改；结构化标注另存`labeled_results.csv`。

## 控制条件与限制

| 条件 | 核对结果 |
| --- | --- |
| 父样本ID与审计数据 | 14个ID、17个数据区完全一致，哈希自动核对 |
| 输入包顺序 | 依P1、P2、P3；历史批次一次性提供多包 |
| 模型可见标识 | 均为DeepSeek Harness subagent（deepseek-flash） |
| 模型快照、温度、最大输出、工具权限 | 未完整记录，不能宣称严格同参 |
| 原始输入 | 保存prepared包全文；历史运行器完整隐藏包装不可得 |
| 原始输出 | 子代理最终JSON，不能称为token级流式原文 |
| 上下文隔离 | 源协议记录为每条独立子代理上下文，本次无法追溯运行器内部状态 |
| 标签 | 使用已存在的14条主条件人工验证标签；17条条件证据另存 |
| 盲评 | 历史为子代理辅助证据复核，不等于人工版本盲评 |
| 运行时延与Token | 原始记录不存在，保持空值 |
| 失败与重试 | 保留原v1 SQLI-001预试验；不因协议失败剔除记录 |
| 调优污染 | v3使用同集反馈且对CMD-004包含负例线索，非独立测试集 |

任务书没有要求商业API。API或独立代理都必须记录可取得的模型参数、调用边界与实际偏差；不能仅凭模型名称相同就判定完全可比。

## 标签与指标

以`ground_truth.csv`中的`main_condition=yes`为父样本评测单位。AUTH-001主条件为low，其他配置用于错误解释，不能复制父标签至所有条件。TP/FP/FN/TN按同一单位配对；无法判定记U。分母为零记不适用，未执行记待测。

四项显式证据字段检查规则与脚本一致：所有finding有非空有效位置字段、字符串数组形式的数据流及前置条件，响应有合法结论状态。阴性采用排除结构，缺独立数据流及前置条件字段时不自动从叙述中补齐。本指标有结构偏差，不能直接用作语义质量评分。

POC以生成的代码对象为单位，按finding计数，不按父样本数计数。相同脚本用于不同角色或目标时仍保留各finding记录；如后续去重，需另外报告唯一脚本数及方法。可运行率分母为全部生成代码对象，成功分子必须有该原稿哈希对应的执行证据。语法通过不计成功，人工重写不计原稿成功。

## 复算与新增实验分离

`tools/build_analysis.py`是历史复算器，会重建派生CSV。新增POC结果应写入单独的`followup_poc_results.csv`，不能填入会被重建覆盖的`poc_execution.csv`。新增模型实验另开批次，不能回填或修改历史原文。
