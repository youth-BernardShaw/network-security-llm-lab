## 对照代码

以下假设$pdo为已建立连接的PDO对象，id为字符串形式的请求参数：

```php
$id = $_GET['id'];
$stmt = $pdo->prepare(
    'SELECT user_id, username FROM users WHERE id = :id LIMIT 1'
);
$stmt->bindValue(':id', $id, PDO::PARAM_STR);
$stmt->execute();
$row = $stmt->fetch(PDO::FETCH_ASSOC);
```

## 语法检测

用户输入赋给$id，随后通过bindValue绑定到固定查询中的:id占位符，再调用execute执行。

数据流：用户输入 → 参数绑定 → 固定SQL模板执行。
